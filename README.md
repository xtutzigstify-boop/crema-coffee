# ☕ Крема — кофейня (Fetch API · Express · WebSocket)

Учебный проект по теме **«Работа с асинхронными запросами: Fetch API»**.
Свой сервер на Node.js + Express раздаёт HTML-клиент кофейни и REST API, а WebSocket показывает изменения во всех вкладках в реальном времени.

## Запуск с нуля

```bash
npm install        # установит express и ws
node server.js     # или: npm start
```

Откройте **http://localhost:3000** (страницу нужно открывать именно по этому адресу, а не двойным кликом по файлу — иначе `fetch` не найдёт сервер).

В терминале сервера для каждого запроса печатаются метод, путь, статус и время, например:
`12:01:44 GET /api/items 200 3 мс`

## Эндпоинты

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/items` | массив из 5 позиций меню |
| GET | `/api/items/:id` | одна позиция или **404** с JSON `{error}` |
| GET | `/api/orders` | список заказов |
| POST | `/api/orders` | создать заказ (JSON: `name`, `comment`, `items:[{id,size,qty}]`) → 201, ошибки 400 / 409 |
| GET | `/api/chaos/500` | рубильник: всегда **500** |
| GET | `/api/chaos/slow` | рубильник: ответ через **3 секунды** |
| GET | `/api/chaos/broken` | рубильник: **битый JSON** |
| WS | `ws://localhost:3000` | сообщения `hello`, `update` (каждые 5 с), `order`, `status`, `presence` |

## Как проверить каждый пункт задания

**Пульт управляющего** — кнопка ⚙️ в левом нижнем углу. Там рубильники, таймаут, мини-Network и кэш.

| Состояние | Как получить |
|---|---|
| ✅ Успех | открыть страницу |
| 404 | поле «Код позиции» → `999` (или кнопка в пульте) |
| 500 | пульт → «Ответ 500» |
| Задержка / индикатор | пульт → «Задержка 3 с» (таймаут 5 с) |
| Таймаут (abort) | пульт → таймаут «2 секунды» + «Задержка 3 с» |
| Битый JSON | пульт → «Битый JSON» |
| Оффлайн | загрузить меню → DevTools → Network → **Offline** → «Обновить меню» |
| WebSocket | две вкладки: оформить заказ в одной — запасы и лента меняются во второй |

Везде есть понятное сообщение, кнопка **«Повторить»** и индикатор загрузки с кнопкой «Отменить».

**Отмена (canceled).** Выберите «Задержка 3 с» и, пока идёт загрузка, переключите режим на другой — в DevTools → Network первый запрос будет помечен `(canceled)`. Кнопка «Отменить» делает то же вручную.

**Защита от дублей.** Кнопка «Обновить меню» блокируется на время запроса; два быстрых клика → один запрос в Network. Так же защищена кнопка «Оформить заказ».

**Кэш.** Последний успешный ответ хранится в `localStorage` (`crema:menu`) с меткой времени. При ошибке сети/сервера показывается кэш и жёлтая плашка. Кэш старше 5 минут не используется.
